A few useful details

Before we begin.

Can we start with design before development?+

Yes. We can begin with product discovery, user flows, wireframes or a prototype, then use that work to define the development scope.

Can you work with an existing product?+

Yes. We can review an existing experience, work through specific usability problems or help shape the next part of the product.

Are the featured projects available to try?+

The featured work is ongoing. The project overviews describe the current design and development scope; public product demos are not linked at this stage.

What should I include in a project inquiry?+

A short description of the problem, who the product is for, what already exists and any timing constraints is a useful start. The project brief template above can help organize your thoughts.
